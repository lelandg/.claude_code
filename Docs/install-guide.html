Install the Claude Code config in three commands.

This guide walks you through installing a production-tested Claude Code configuration — custom agents, skills, settings, and plugins — even if you've never touched a config file before. Every command has a copy button: click it, paste into your terminal, done.

What you're installing

Claude Code keeps its personal configuration in a hidden folder in your home directory called ~/.claude/. This repository is a real-world, battle-tested version of that folder that you can copy onto your own machine. After installing, Claude Code gains:

ComponentWhat it gives you
6 custom agentsSpecialists for code review, engineering, performance, docs, research, and testing
14+ skillsRepeatable workflows like CodeMap maintenance, doc generation, and knowledge graphs
CLAUDE.mdGlobal instructions Claude reads every session — security rules, date handling, conventions
settings.jsonSensible permissions, enabled plugins, and a custom status line
Output stylesThree formatting modes: GenUI, HTML, and Technical Quality
🦎

Heads up on platform: this config is written for Linux, WSL, or macOS. On native Windows without WSL, see the conversion prompt in the README's Platform section first.

1

Check your prerequisites

You need two things: git (to download the repo) and Claude Code itself. Open a terminal and run each check below.

Is git installed?

terminal
git --version

If you see a version number (like git version 2.43.0), you're good. If not, install it from git-scm.com.

Is Claude Code installed?

terminal
claude --version

No version number? Install Claude Code with npm:

terminal
npm install -g @anthropic-ai/claude-code

Full installation docs live at docs.anthropic.com/claude-code. Run claude once after installing — it creates the ~/.claude/ folder this config installs into.

2

Install the config (the easy way)

The repo ships with its own installer — a slash command that compares every file against what you already have, shows you diffs, and asks before overwriting anything. It even backs up replaced files automatically. This is the recommended path.

2a · Clone the repo and open Claude Code inside it

terminal
git clone https://github.com/lelandg/.claude_code.git
cd .claude_code
claude .

2b · Run the installer inside Claude Code

Once Claude Code opens, type this and press Enter:

inside claude code
/install-claude-config

The installer will:

  • Scan every file and show you a table — NEW, CHANGED, or IDENTICAL
  • Show a diff for each changed file and ask: Install / Keep current / Smart merge
  • Smart-merge settings.json and CLAUDE.md so your personal values survive
  • Back up anything it overwrites to ~/.claude/.backup/<date>/
💡

First time using Claude Code? Slash commands are typed directly into the Claude Code prompt — the same place you'd type a question. They start with / and trigger built-in or custom workflows.

Alternative: manual copy (no installer)

If you'd rather not use the installer — for example, on a fresh machine with no existing config to protect — copy everything in one shot:

terminal
git clone https://github.com/lelandg/.claude_code.git
cp -r .claude_code/claude/* ~/.claude/
⚠️

This overwrites without asking. If you already have files in ~/.claude/, back them up first: cp -r ~/.claude ~/.claude.backup

Alternative: cherry-pick just what you want

Only want part of the config? Run any of these from inside the cloned repo:

terminal — pick & choose
# Just the agents
cp claude/agents/*.md ~/.claude/agents/

# Just the skills
cp -r claude/skills/* ~/.claude/skills/

# Just the output styles
cp claude/output-styles/*.md ~/.claude/output-styles/

# Just the global instructions file
cp claude/CLAUDE.md ~/.claude/CLAUDE.md
3

Personalize it (4 quick edits)

The config ships with placeholders so no one's personal info leaks into the repo. Make these four changes and you're done.

3a · Put your name in CLAUDE.md

Open ~/.claude/CLAUDE.md in any editor and replace the placeholder contact table at the top with your own details:

~/.claude/CLAUDE.md
| Your Name | your-github-username | your-discord-username |

3b · Fix the username in settings.json

Open ~/.claude/settings.json, find the line below, and replace <YOUR_USER> with your actual username (run whoami in a terminal if unsure):

~/.claude/settings.json
"Read(//home/<YOUR_USER>/.claude/**)"

3c · Set your GitHub token (for the GitHub MCP server)

The config includes a GitHub integration that lets Claude read repos, issues, and PRs. It needs a personal access token. Create one at github.com/settings/tokens with the repo, read:org, and read:user scopes, then add it to your shell profile:

add to ~/.bashrc or ~/.zshrc
export GITHUB_PERSONAL_ACCESS_TOKEN="ghp_your_token_here"

Then reload your shell so the variable takes effect:

terminal
source ~/.bashrc
🔒

Never paste your token into a file inside a git repo — only into your shell profile (~/.bashrc). Tokens committed to git get scraped by bots within minutes.

3d · Restart Claude Code

Exit Claude Code (/exit or Ctrl+C) and start it again. The new config loads on startup.

4

Install plugins from the marketplace

Plugins extend Claude Code with extra skills, agents, and integrations — and Claude Code has a built-in plugin marketplace. This config enables a curated set in settings.json; you install them with one command each.

Open the plugin manager

Inside Claude Code, run:

inside claude code
/plugin

This opens an interactive browser where you can search the official marketplace, view plugin details, and install with Enter. Install any of these that sound useful — they're the ones this config expects:

PluginWhat it does
superpowersAdvanced workflows: TDD, systematic debugging, planning
code-reviewCode review workflow with PR integration
commit-commandsGit commit, push, and PR creation skills
frontend-designFrontend design skills and workflows
feature-devGuided feature development workflow
security-guidanceSecurity best practices and vulnerability analysis
context7Fetches up-to-date library documentation
example-skillsAnthropic's example skill collection (PDF, DOCX, design…)

Adding third-party marketplaces

Beyond the official marketplace, you can register any GitHub repo that publishes plugins:

inside claude code
/plugin marketplace add owner/repo-name
🧪

Language server plugins (pyright-lsp, typescript-lsp, csharp-lsp, clangd-lsp) are enabled in this config but need their language toolchains installed. Disable any you don't use in ~/.claude/settings.json under enabledPlugins.

5

Verify everything works

After restarting Claude Code, run through this checklist:

  • Status line — the bottom bar should show user@host:/path plus your model and git branch
  • Skills loaded — type / and you should see commands like /install-claude-config in the list
  • Agents working — ask "review this code" on any file; the code-reviewer agent should activate
  • GitHub MCP — ask Claude about one of your GitHub repos; it should fetch real data
  • No placeholders — your name is in CLAUDE.md, your username is in settings.json
✅

All green? You're done. Claude Code is now running with the full Chameleon Labs configuration.

Something not working?

SymptomFix
Skills don't show upRestart Claude Code; check ~/.claude/skills/<name>/SKILL.md exists

GitHub MCP failsRun echo $GITHUB_PERSONAL_ACCESS_TOKEN — empty means the token isn't set
Plugins not loadingRestart Claude Code; check names under enabledPlugins in settings.json
Agents not appearingVerify the .md files in ~/.claude/agents/ kept their --- frontmatter
